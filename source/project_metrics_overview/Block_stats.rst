Block Stats Overview
=======================


.. grid:: 2
   :gutter: 2

   .. card:: 🧩 **Block Labels**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #block-labels

      - Types like `COMMENT`, `DataStep`, `LETMACRO`, `LIBNAME`, etc.
      - Categorizes each block by function or structure.

   .. card:: 🧠 **Complexity**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #block-complexity

      - Indicates how complex a block is to process or understand.
      - Useful for targeting blocks that may need refactoring.

.. grid:: 2
   :gutter: 2

   .. card:: 📄 **Lines of Code**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #block-lines

      - Shows the number of lines per block.
      - Helps identify large or small blocks at a glance.

   .. card:: 🔄 **Processed Blocks**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #block-processed

      - Number of blocks that have been processed or analyzed.
      - Reflects workflow progress.

.. grid:: 2
   :gutter: 2

   .. card:: ✅ **Passed Blocks**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #block-passed

      - Successfully passed validation or test steps.

   .. card:: ❌ **Failed Blocks**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #block-failed

      - Blocks that failed one or more processing criteria.

.. grid:: 2
   :gutter: 2

   .. card:: 🐞 **Errors**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #block-errors

      - Tracks the number of errors found in each block.
      - Helps identify problematic code areas.

   .. card:: 📤 **CSV Export**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #block-csv

      - Export current table view to a `.csv` file.
      - Useful for external analysis or audit logs.

.. grid:: 1
   :gutter: 2

   .. card:: ↕️ **Sort & Filter**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #block-sort

      - Sort blocks in ascending or descending order.
      - Use **Apply** to filter and **Reset** to clear selections.
