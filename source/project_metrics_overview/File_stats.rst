File Stats Overview
=======================

.. grid:: 2
   :gutter: 2

   .. card:: 📤 **CSV Export**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #csv-export

      - Export the currently displayed File Stats data.
      - Generates a `.csv` file for use in spreadsheets or reporting tools.

   .. card:: 📄 **Lines in File**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #lines-in-file

      - Filter files based on the total number of lines.
      - Use minimum and maximum values to narrow down results.

.. grid:: 2
   :gutter: 2

   .. card:: 🧾 **Lines of Code**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #lines-of-code

      - Focus on files based on actual lines of code.
      - Useful for identifying larger or smaller code files.

   .. card:: 🧠 **Complexity**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #complexity

      - Filter by complexity score of the file.
      - Helps surface files that are simple or highly complex.

.. grid:: 2
   :gutter: 2

   .. card:: 📦 **Total Blocks**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #total-blocks

      - Apply filters by total number of logical/code blocks.
      - Useful for analyzing code structure and segmentation.

   .. card:: ✅ **Passed Blocks**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #passed-blocks

      - Filter files with a minimum or maximum number of passing blocks.
      - Helps identify well-tested files.

.. grid:: 2
   :gutter: 2

   .. card:: ❌ **Failed Blocks**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #failed-blocks

      - View files with test or validation failures.
      - Use range filters to isolate high-failure files.

   .. card:: 🐞 **Errors**
      :class-card: sd-shadow-xs sd-rounded sd-bg-white sd-border sd-padding-sm sd-text-sm
      :link: #errors

      - Filter based on number of detected errors in each file.
      - Useful for identifying problematic or buggy files.
